# Project Scope

## In Scope

The system includes functionality for:
- detailed skin data input,
- price prediction using ML models,
- visualization of historical trends,
- factor influence analysis,
- automated data synchronization,
- API documentation and containerized deployment.

## Out of Scope

Excluded functionality:
- trading execution,
- payments,
- social interaction.

## Assumptions

- Availability of external APIs
- Sufficient data quality
- User familiarity with CS2 skins

## Constraints

| Category | Description |
|--------|-------------|
| Time | Diploma schedule |
| Budget | Academic scope |
| Technology | ASP.NET Core, PostgreSQL |
| Security | GDPR compliance |
| Load | ≤ 500 concurrent users |
